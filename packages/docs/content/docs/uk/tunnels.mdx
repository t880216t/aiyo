# Тунелі

Тунель — це публічне посилання на ваш AiYo, щоб дістатися до нього з телефона чи з іншої мережі. Скористайтеся `aiyo tunnel`, щоб створити його для запущеного інстансу.

## Передумови

AiYo запускає CLI провайдера тунелю на вашій машині. Спочатку встановіть провайдера, який хочете використовувати:

```bash
brew install cloudflared
brew install ngrok
```

Швидкі тунелі Cloudflare працюють через `cloudflared`. Для Ngrok потрібен акаунт ngrok і authtoken з dashboard ngrok:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

## Швидкий старт

1. Запустіть AiYo:

```bash
aiyo
```

Якщо пропустити цей крок, `aiyo tunnel start` може автоматично запустити CLI server. Під час auto-start можна передати server options: `--port`, `--host`, `--lan`, `--ui-password` і `--api-only`.

2. Запустіть тунель Cloudflare:

```bash
aiyo tunnel start --provider cloudflare --mode quick
```

Або запустіть тунель Ngrok:

```bash
aiyo tunnel start --provider ngrok --mode quick
```

3. Перевірте статус:

```bash
aiyo tunnel status
```

Коли тунель піднято, `status` показує публічний URL. Відкрийте його або відскануйте QR-код, щоб дістатися до AiYo звідусіль.

Типово AiYo виводить QR-код в інтерактивних TTY-сесіях. Використовуйте `--qr`, щоб примусово вивести QR, або `--no-qr`, щоб вимкнути його.

## Провайдери

- `cloudflare`: quick, managed remote і managed local режими
- `ngrok`: quick режим

## Керовані режими

### Кероване віддалене

Використовуйте токен + хостнейм, керовані Cloudflare:

```bash
aiyo tunnel start --provider cloudflare --mode managed-remote --token-file ~/.secrets/cf-token --hostname app.example.com
```

### Кероване локальне

Використовуйте локальний конфіг `cloudflared`:

```bash
aiyo tunnel start --provider cloudflare --mode managed-local --config ~/.cloudflared/config.yml
```

## Профілі (managed-remote)

Збережіть багаторазовий профіль:

```bash
aiyo tunnel profile add --provider cloudflare --mode managed-remote --name prod-main --hostname app.example.com --token-file ~/.secrets/cf-token
```

Запуск зі збереженим профілем:

```bash
aiyo tunnel start --profile prod-main
```

## Корисні команди

```bash
aiyo tunnel providers
aiyo tunnel ready --provider cloudflare
aiyo tunnel ready --provider ngrok
aiyo tunnel doctor --provider cloudflare
aiyo tunnel doctor --provider ngrok
aiyo tunnel stop --port 3000
```

## Нотатки щодо поведінки

- один активний тунель на інстанс AiYo (порт)
- запуск нового режиму/провайдера на тому самому інстансі замінює попередній тунель
- генерація нового посилання для підключення відкликає попереднє невикористане
