# Теми

AiYo підтримує вбудовані теми та власні JSON-файли тем.

## Додати власну тему

1. Створіть директорію тем:

```bash
mkdir -p ~/.config/aiyo/themes
```

2. Додайте свій JSON-файл у цю директорію (наприклад, `my-theme.json`).
3. Відкрийте AiYo, потім перейдіть до **Settings -> Theme -> Reload themes**.
4. Оберіть свою тему зі спадного списку. Вона застосується одразу.

## Розташування тем

- macOS/Linux: `~/.config/aiyo/themes/`
